=================
Open index.html in a web browser to view the site.

To put it online, upload EVERYTHING in this folder (index.html, img/, music/,
paolostk_EPK.pdf) to any web host, e.g. Netlify Drop (app.netlify.com/drop),
GitHub Pages, or your domain's hosting. Keep the folder structure the same.
